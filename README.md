## Features

**Crunchy Crunchy Advancements** is a mod that, by default:

- Removes the advancements button on the pause screen
- Unbinds and removes the advancements keybind from options
- Disables toast notifications for advancements and recipe unlocks
- Prevents chat announcements for advancements
- Prevents recipe advancements from loading

## Configuration

Crunchy Crunchy can be configured via `config/crunchy_crunchy_advancements.toml`, including:

- What advancements should be filtered from loading (with blacklist/whitelist modes)
- Toggles for each of the above default features

Mods like Patchouli require advancements for progression, so this mod doesn't remove all advancements by default.<br/>
To load even fewer advancements, swap to whitelist mode and individually filter these mods by namespace.
